# Бесплатный IQ-тест

Статический IQ-тест на чистом HTML, CSS и JavaScript. Без сборки, без зависимостей и без сервера: всё работает в браузере, ответы никуда не отправляются.

## Что внутри

- 30 оригинальных заданий пяти типов: числовые ряды, буквенные ряды, вербальная логика, логические задачи, визуальные матрицы (рисуются в SVG).
- Таймер на 25 минут; по его окончании тест завершается автоматически.
- Порядок вариантов перемешивается при каждом прохождении.
- Прогресс сохраняется в `localStorage`, тест можно продолжить после перезагрузки.
- Результат: оценка IQ, процентиль, график нормального распределения, разбивка по типам заданий и разбор ответов с объяснениями.
- Адаптивная вёрстка, тёмная тема, управление с клавиатуры (1–6, ← →).

## Как считается результат

Задания имеют вес 1–3 в зависимости от сложности (максимум 62 балла). Доля набранных баллов переводится в шкалу IQ со средним 100 и σ = 15, исходя из допущения, что средний человек набирает около половины баллов. Итог ограничен диапазоном 55–145. Это развлекательная оценка, а не клиническое измерение.

## Запуск локально

```sh
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/free-iq-test/`.

## Структура

```
index.html        разметка экранов
css/style.css     стили (светлая и тёмная тема)
js/questions.js   банк вопросов
js/app.js         логика теста, таймер, подсчёт, рисование матриц
```

Чтобы добавить вопрос, допишите объект в `js/questions.js` (поля описаны в комментарии в начале файла).
